# Spec Delta

## Purpose

Defines core reusable UI primitives including Big Tech minimalist pill buttons, liquid glassmorphic bento cards, and avant-garde visual accents like chrome sparkles and HUD metadata badges.

## ADDED Requirements

### Requirement: Big Tech Pill Buttons
The design system SHALL provide fully rounded pill buttons (`border-radius: 9999px`) in standardized 8-pixel aligned heights (32px, 48px, 56px) supporting primary electric blue and secondary glass variants.

#### Scenario: User interaction on pill button
- **WHEN** a user hovers over a primary pill button
- **THEN** the button scales subtly and displays an ambient electric blue glow effect

### Requirement: Liquid Glassmorphic Bento Cards
Card containers SHALL provide glassmorphic backgrounds, subtle light-catching borders, rounded corners matching 8-pixel intervals (16px, 24px, 32px), and micro-interaction states.

#### Scenario: Card hover interaction
- **WHEN** a user hovers over a glassmorphic card
- **THEN** the card renders a smooth specular elevation transition without breaking background transparency

### Requirement: Avant-Garde Visual Accents
The component library SHALL provide edgy accent elements including 4-point chrome star sparkles, iridescent particle highlights, and technical monospace HUD metadata badges.

#### Scenario: Rendering HUD tags and star accents
- **WHEN** case study previews or hero sections display status or category badges
- **THEN** badges render with monospace typography, bordered outlines, and optional sparkling chrome glyphs
